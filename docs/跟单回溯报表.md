# 跟单回溯报表

> 版本说明与改动清单见 **`docs/更新日志_V6.md`**。

## 作用

在运行 **`npm run dev`**（实盘）或 **`npm run dryrun`**（模拟）时，自动在 MongoDB 中：

- 创建 **会话**（`copy_tracking_sessions`）：记录本次进程启动时间、代理钱包、当时的跟单地址列表、运行模式 `live` / `dryrun`。
- 写入 **成交流水**（`copy_tracking_entries`）：每笔**真实或模拟成交**（买入/卖出）、市场标题、交易员显示名、**正买/反买**、交易员/我方 outcome 文案、USD 与代币数量、卖出已实现盈亏（若有）等。

便于按交易员做 **成功下单次数、买卖金额、已实现盈亏、已结算市场的输赢视角** 复盘。

## 反买（REVERSE）

流水与 Excel 中均带有 **「反买复盘说明」**：二元市场里，交易员侧 token 若结算为「赢」，你跟单的 **对侧 token** 一般为「输」——导出表会以 Gamma **结算价** 分别计算 **交易员 token / 我跟单 token** 的近似输赢列，避免与正买混淆。

## 环境变量

| 变量 | 说明 |
|------|------|
| `COPY_TRACKING_ENABLED` | 默认启用；设为 `false` 则不再写入新流水（仍可导出历史）。 |
| `COPY_TRACKING_REPORT_DIR` | 导出 Excel 的目录，默认 `reports`。 |

## 导出 Excel

```bash
# 导出最近一次会话（推荐）
npm run copy-tracking-export -- --last-session

# 指定会话 ID（启动日志里会打印）
npm run copy-tracking-export -- --session live_1730000000000_a1b2c3d4

# 不按会话：最近 14 天流水（最多 5000 条）
npm run copy-tracking-export -- --days 14
```

生成文件示例：`reports/copy-tracking-<会话或export>-<时间>.xlsx`。

### 工作表说明

1. **成交流水**：每笔成交一行，含市场是否已收盘、双方 token 结算价、**反买说明** 等。
2. **按交易员汇总**：买入/卖出笔数、买入总额、卖出回款、卖出已实现盈亏合计。
3. **市场结算视角**：按 `交易员 + conditionId` 聚合，便于按市场复盘。

## 技术说明

- 结算价来自 Gamma（与 `gammaSettlement` 一致）；**进行中**市场无最终输赢。
- 会话在进程 **正常退出（SIGINT 等）** 时会写入 `endedAt`；若进程被强杀，可能仅有 `startedAt`。
