# 更新日志 V6

更新时间：2026-03-22

---

## 本版重点

V6 主要新增 **跟单回溯与 Excel 复盘报表**：在运行 **`npm run dev` / `npm start`（实盘）** 或 **`npm run dryrun`（模拟）** 时，自动在 MongoDB 记录 **会话 + 每笔成交流水**，并可通过命令导出 **`.xlsx`**，按交易员汇总笔数与金额、按市场查看结算视角；**反买（`USER_ADDRESSES_REVERSE`）** 在表中带有专门说明列，避免与正买结果混淆。

---

## 新增功能：跟单回溯

### 行为说明

1. **进程启动即创建会话**（`copy_tracking_sessions`）
   - 字段含：`sessionId`、`runMode`（`live` / `dryrun`）、`startedAt`、`proxyWallet`、当时的 **`traderAddresses`** 列表。
   - **正常退出**（如 Ctrl+C 触发优雅关闭）时写入 **`endedAt`**；进程被强杀可能仅有 `startedAt`。

2. **每笔成功成交写流水**（`copy_tracking_entries`）
   - **实盘**：在 **`postOrder.ts`** 中，买入/卖出 **实际成交金额大于 0** 后写入。
   - **模拟**：在 **`dryRunExecutor.ts`** 中，模拟买入/卖出 **成交后** 写入（与实盘字段对齐，符合 Dry Run / 实盘一致性规则）。
   - 记录内容包含：交易员地址与 **显示名**（`pseudonym` / `name`）、**市场标题**、`conditionId`、`slug`、**跟单模式**（`FOLLOW` / `REVERSE`）、交易员原方向与 **我方成交方向**、outcome 文案、**USD**、**代币变动**、卖出时的 **已实现盈亏**（若有）、交易员 `txHash`、活动 `activityObjectId` 等。

3. **反买复盘**
   - 流水与导出表中包含 **「反买复盘说明」**：二元市场下，交易员侧 token 若结算为「赢」，你跟单的 **对侧 token** 一般为「输」；导出时会结合 Gamma **结算价** 分别给出 **交易员 token / 我跟单 token** 的近似输赢列（已收盘市场）。

### 导出 Excel

- **命令**：`npm run copy-tracking-export`
- **常用参数**：
  - `--last-session`：导出 **最近一次** 会话的全部流水。
  - `--session <会话ID>`：启动日志中会打印会话 ID。
  - `--days <N>`：不按会话，导出最近 N 天（最多 5000 条）。
- **输出目录**：`ENV.COPY_TRACKING_REPORT_DIR`（默认 **`reports/`**），文件名形如 `copy-tracking-<会话或 export>-<时间>.xlsx`。
- **工作表**：
  1. **成交流水**：逐笔明细 + 市场是否已收盘、双方 token 结算价、反买说明等。
  2. **按交易员汇总**：买入/卖出 **笔数**、买入总额、卖出回款、卖出已实现盈亏合计。
  3. **市场结算视角**：按 **交易员 + conditionId** 聚合，便于按市场复盘。

### 依赖

- 新增 **`exceljs`**（`package.json` `dependencies`），用于生成 `.xlsx`。

## 新增 / 涉及配置（`.env` / `.env.example`）

```env
# 跟单回溯（Mongo：copy_tracking_sessions / copy_tracking_entries）
# false = 关闭写入（仍可用 npm run copy-tracking-export 导历史）
COPY_TRACKING_ENABLED = true
# 导出 Excel 目录
COPY_TRACKING_REPORT_DIR = reports
```

- 支持 **`.env` 热重载** 更新上述两项（与 V5 热更机制一致）。

## 注意事项

- 关闭回溯写入：设置 **`COPY_TRACKING_ENABLED=false`**，不再产生新流水；历史数据仍可导出。
- **Mongo 与网络**：导出脚本会按流水中的 `conditionId` 请求 Gamma 以填充结算列；网络异常时部分单元格可能为空。
- 请勿将含密钥的 **`.env`** 提交到版本库；`.env.example` 已与说明同步，本地 `.env` 请自行对齐。
