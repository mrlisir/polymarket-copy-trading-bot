# 更新日志 V8

更新时间：2026-03-23

---

## 本版重点

V8 重点解决两个与实盘体验相关的问题：

1. **临近结束市场，跟单容易“买入后很快没流动性/被动平仓”**的问题
2. **自动止盈止损（TP/SL）触发口径与实盘不一致**，导致“看起来 ROI 到了但未触发卖出”的偏差

---

## 新增功能：临近 endDate 跳过跟单（仅 BUY）

当跟单执行前检测到该市场 `endDate` 距离当前不足 `N` 分钟，则直接跳过该条 **BUY** 跟单，避免临近结算时流动性消失导致买入后立即“没法卖/触发其他清仓逻辑”。

### 行为说明

- 生效范围：**实盘以 polymarket `positions` API 为准**
- 只对 **BUY 跟单**生效（SELL 不需要这个判断）
- 判断字段：交易对应的 `conditionId` 在 `user_positions` 中的 `endDate`

### 新增配置项

在 `.env` / `.env.example` 中新增：

- `COPY_SKIP_FOLLOW_IF_ENDS_WITHIN_MINUTES`：当 `endDate - now < N分钟` 时跳过跟单
- 默认：`5`
- `0` 或负数：关闭该跳过逻辑

## 修复：自动止盈止损触发口径改为“仅按 polymarket positions ROI”

之前自动止盈止损在触发计算中引入了 **orderbook best bid** 作为更保守的执行价估值，并使用 `min(posROI, bidROI)` 做触发判断，可能导致出现：

- “positions API 口径 ROI 已经越过 TP/SL”
- 但触发条件仍被 bid 口径抑制，从而未触发卖出

V8 调整为：

- **触发判断只使用 `polymarket positions` 返回的 ROI（`pos.percentPnl` / initialValue-currentValue 推导口径）**
- 不再使用 orderbook bid 来改变触发阈值

---

## 稳定性增强：positions 延迟反映时保留 watch（实盘 + dryrun）

针对 positions API 在短窗口内可能出现 `size<=0` / 新买入尚未反映的问题：

- 增加“宽限期（grace period）”
- 在宽限期内如果检测到 positions 未反映/tracked BUY 暂不可见：**不立刻丢弃 watch**
- 在后续 tick 中继续计算 TP/SL，直到可计算出 PnL 并触发卖出

---

## 无流动性处理策略（避免误清理）

当自动止盈止损触发后尝试卖出，但出现：

- `soldTokens≈0 && proceedsUsd≈0`（通常是订单簿缺失/无买方报价等）

V8 的行为是：

- **如果该仓位在 positions API 中标记为 `redeemable/mergeable`：停止跟踪并清理 tracked BUY**
- **否则保留 watch，让冷却后继续重试**（避免“临时盘口空窗”导致永久不再卖出）

---

## 修复：`AUTO_PROFIT_EXIT_STOP_LOSS_PCT=0` 误当成「无止损」

旧逻辑条件为 `percentPnl <= -SL`，当 `SL=0` 时等价于 `percentPnl <= 0`，**任意浮亏都会触发止损**。

现改为：**`AUTO_PROFIT_EXIT_STOP_LOSS_PCT <= 0` 表示关闭止损**；同理 **`AUTO_PROFIT_EXIT_TAKE_PROFIT_PCT <= 0` 表示关闭止盈**（避免 `TP=0` 变成「任意非负即卖」）。

---

## 修复：极低价（如 1¢）仓位误报「触发止盈」

**现象**：Positions API 在极低价 outcome 上常把 `initialValue` / `avgPrice` 舍入成 `0`，但 `percentPnl` / `currentValue` 仍可能异常偏大，导致日志出现「4150% 止盈、买入成本≈$0」；同时旧逻辑要求 `pos.avgPrice > 0` 才执行止盈前的**订单簿成交额 / 可执行 PnL**校验，结果校验被整段跳过，直接打印「触发止盈」并尝试卖出（无买盘时又会失败）。

**修复**（实盘 + dryrun 一致）：

- 新增参考成本价：`resolveRefAvgPriceForExit` —— 优先 `pos.avgPrice`，无效则用 **本地记录投入 `trackedCostBasisUsd ÷ 持仓 size`**
- 止盈前盘口保护一律用该参考价；无有效参考价则**跳过本轮止盈**并打日志说明
- 触发日志中同时打印 **API 初始成本 / 本地投入 / 参考成本价**，便于区分「API 失真」与真实投入
